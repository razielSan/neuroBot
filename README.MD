 # 🤖 NeuroBot — Telegram-бот для генерации изображений и анализа картинок

NeuroBot — это удобный Telegram-бот, который позволяет:
- генерировать изображения с помощью разных нейросетей;
- получать описания изображений с помощьюе нейросетей
- генерировать короткие видео по изображен#ия с помощью нейросетей
- использовать несколько внешних API (Caila, StableHorde, Vheer, Pollinations);
- отслеживать прогресс генерации в реальном времени;
- безопасно отменять выполнение задач.
